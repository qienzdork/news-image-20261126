# news-image-20261126 — The World in One Day

A newspaper front page summing up Thursday 26 November 2026: the Houthi
claim of a strike on Saudi Arabia's Ras Tanura refinery with Brent crude
above $94, the US plan for new tariffs on China, the EU, Japan and Brazil,
Pakistan's first astronaut flying to China's Tiangong station, the Cairo
fuel-tanker fire that killed 30, drone strikes killing 19 civilians in
Sudan's Blue Nile state, 20 hostages freed in Colombia, and the storm that
postponed the Macy's Thanksgiving parade for the first time in 100 years.

`main.py` is pure Python standard library: it draws the whole page with a
built-in 5x7 bitmap font and writes a deterministic PNG to
`$OUTPUT_DIR/entry.png` (default `/output`). Run it twice and the bytes are
identical.
